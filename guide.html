How to use MeToo

Back to the app

What the app does

  • 2 taps: your trusted contacts get a message with your location.
  • 3 taps: loud siren, and your contacts are alerted. The siren stops only with your PIN.
  • Get help: rights, counselling, how to file a complaint, and private notes. Everything stays on your phone.
Important: a website cannot send a text by itself. After 2 taps the message opens ready to go, and you press Send. Only the Android APK app sends automatically.

1. Install (iPhone)

  1. Open the MeToo link in Safari (not Chrome).
  2. Tap the Share button (square with arrow).
  3. Tap Add to Home Screen, then Add.

2. Give permission

  1. Open the installed MeToo app. When it asks for location, tap Allow While Using App.
  2. If you tapped Don't Allow: Settings > Privacy & Security > Location Services. Make sure it is On. Scroll to Safari Websites (or MeToo) and choose While Using the App. Turn on Precise Location.
  3. In MeToo, Contacts tab, tap Check location. It should say "Location works".

3. Set up

  1. Contacts tab: add 2 trusted people.
  2. Set a PIN. Without a PIN anyone can stop the siren.

4. Emergency icon

  1. In Safari, open the MeToo link and add panic.html at the end of it.
  2. Share > Add to Home Screen. This is the red "MeToo SOS" icon.
  3. Tap the icon once (that is tap 1), then touch the screen once more within 2.5 seconds (alert), or twice more (siren).
Siren volume: raise your phone volume and turn off Silent mode (the switch on the side). The browser cannot do this for you.

1. Install (Android website version)

  1. Open the MeToo link in Chrome.
  2. Tap the menu (three dots), then Install app or Add to Home screen.

2. Give permission

  1. When asked for location, tap While using the app and turn on Use precise location.
  2. If you said no: long-press the MeToo icon > App info (or Chrome > Settings > Site settings > Location) > Permissions > Location > Allow.
  3. Contacts tab > Check location.

3. APK app (automatic SMS)

  1. Install the APK file you were given. Allow "install unknown apps" if asked.
  2. On first launch allow Location, then SMS.
  3. If SMS is greyed out: Settings > Apps > MeToo > three dots > Allow restricted settings. Then Permissions > SMS > Allow.
  4. Set a screen lock (PIN, pattern or fingerprint) on the phone. The siren is stopped with it.

4. Set up

  1. Contacts tab: add 2 trusted people. Test with your own number first.

How to use in an emergency

  1. Tap the app icon. Opening it is tap 1.
  2. Touch the screen once more within 2.5 seconds: your contacts get your location.
  3. Touch twice more: siren starts.
  4. To stop the siren, enter your PIN (APK app: phone password or fingerprint).
Opened it by mistake? Do nothing for 2.5 seconds and nothing is sent.

Test before you need it

  • Use your own number as a contact.
  • Do a 2-tap test, then a 3-tap test with the volume low.
  • Tell your contacts about MeToo so they know what the message means.

Privacy

  • Contacts, notes and PIN stay on this phone only. Nothing is uploaded.
  • Use Quick exit (top of the app) to leave fast. It does not stop a running siren.
  • You can set an app lock PIN so others cannot open your notes.

Not working?

  • No siren sound: volume up, Silent mode off, touch the screen once.
  • No location: check the permission steps above, and turn on GPS / Location Services.
  • Old version showing: close the app fully and open it again.
